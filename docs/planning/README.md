# Planning records

These are point-in-time working documents, not current documentation. They
were written as `buoy` was designed and built, and they are kept because the
reasoning in them is often more useful than the conclusions — particularly
the story specs, each of which carries a Dev Agent Record of what was
actually tried, what broke, and what was deliberately left undone.

**For how `buoy` behaves today, read the [README](../../README.md).** Where
these documents disagree with it, they are the ones that are out of date.

| | |
| --- | --- |
| [`prd/`](prd/) | Problem statement, scope, requirements, open questions |
| [`architecture/`](architecture/) | System design and the numbered ADRs |
| [`epics/`](epics/) | One spec per story, with its Dev Agent Record |
| [`brainstorm-2026-08-06.md`](brainstorm-2026-08-06.md) | The session everything started from |

Some documents reference paths under `_bmad-output/` — retrospectives and
readiness reports produced by the planning tooling. Those are developer-local
and not part of this repository.
